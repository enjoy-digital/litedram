# Altera Cyclone V DDR3 support

LiteDRAM supports Cyclone V DDR3 through a native single-rank, quarter-rate
DFI PHY. It drives the Cyclone V `ALTDQ_DQS2` byte lanes and hard I/O FIFOs,
and assembles two AFI beats into each DFI read word. LiteDRAM firmware runs the
DDR3 initialization sequence. The PHY configures the board's fixed I/O and
FIFO settings at startup.

## Cyclone V GT Development Kit

The native backend was verified on the kit's **64-bit DDR3B bank at 600 MT/s**.
The memory clock is 300 MHz, AFI runs at 150 MHz, and the LiteDRAM system runs
at 75 MHz. DDR3A is wired to the board's hard memory controller and uses a
separate integration.

The PHY uses I/O wrappers generated by Quartus Prime Lite or Standard with
Cyclone V device support. These wrappers cover the PLL, DLL, termination,
command/address pads, and byte lanes.

## BIOS training

The stock LiteX BIOS runs DDR3 initialization, write leveling and read leveling
through the standard LiteDRAM CSRs. The CK and command/address phase is fixed
by the board's PLL configuration.

During write leveling, the PHY drives DQS and reads the DRAM's feedback
through the hard input FIFO. It disables dynamic on-chip termination while
driving the training strobes and restores it when the BIOS exits write leveling.
Each write step advances the pad delay by two taps. Read leveling sweeps the
32 DQ input delay taps per byte lane at single-tap resolution. The fixed BL8
alignment is exposed as one bitslip position. The BIOS then runs a memtest
through the controller.

The PHY returns data in the controller's fixed DFI read slot. The pin timing
audit uses the baseline taps. The BIOS scans measure timing at the board's
current voltage and temperature.

## Timing and validation

Use Quartus TimeQuest to check core setup, hold, recovery, and removal
timing and to audit DDR3B pin timing against the memory and board models.

The 600 MT/s hardware build passed the LiteX BIOS memtest and 18 LiteDRAM BIST
runs with incrementing and PRBS31 patterns at 1, 16, and 64 MiB. The 64 MiB
runs averaged **4.19 GB/s write** and **4.23 GB/s read** with zero errors.
The measurements use LiteDRAM's hardware BIST generator and checker in the LiteX gateware.

Run the focused LiteDRAM tests from the repository root:

```sh
python3 -m pytest -q test/test_c5ddrphy.py test/test_bist.py
```
